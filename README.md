# AliwCall

Vercel-ready mobile-friendly AI receptionist dashboard using Next.js + Supabase.

## Vercel environment variables
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

## MVP features
- Email/password signup and login
- Business onboarding
- Dashboard
- AI agent settings
- Calls
- Leads
- Free monthly minute meter
- Business profile

The Supabase schema is the one already created for AliwCall. Telephony/AI provider integration is the next phase after deployment/auth verification.
